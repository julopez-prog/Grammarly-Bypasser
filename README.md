# Grammarly Blur Toggle

This Manifest V3 browser extension removes CSS blur from elements currently rendered by `grammarly.com`.

## Install in Chrome or Edge

1. Open `chrome://extensions` or `edge://extensions`.
2. Enable **Developer mode**.
3. Select **Load unpacked** and choose this folder.
4. Open or reload a Grammarly page.
5. Open the extension popup and enable **Remove client-side blur**.

The extension does not bypass authentication, request hidden API data, or reconstruct text that is absent from the page source.
